## What the scaffold demonstrates

The uncommitted scaffold was reviewed with **331 passing tests**, Ruff clean,
mypy clean for `src`, `uv lock --check --offline` passing, and
`git diff --check` passing. Package-build and dependency-audit gates are **not**
recorded as passing: an offline build could not resolve the pinned build-system
requirements from the isolated cache, and no current offline vulnerability
advisory source was available. No network request, catalog acquisition,
checkpoint, release data, exclusion, model fit, score, or scientific inference
was produced.

The reviewer trust root is deliberately empty. No reviewer OpenSSH public-key
blob hash is authorized, so acquisition and scientific release loading fail
closed.

## Blocking frozen-schema contradiction

The protocol requires separately identifiable raw and release producers, and
each `ProducerRecord` requires its own source-distribution descriptor. The final
artifact tree and `FinalArtifactMap`, however, permit only one embedded source
tarball and one `source_distribution` artifact. When the release producer is a
later commit than the raw producer, that single tarball cannot truthfully
represent both producers. Implementing either interpretation would violate the
frozen schema.

A prospective **v0.1.4 supersession is required** before implementation or
acquisition. The minimal correction is to bind the raw producer's source
archive externally through the already registered raw checkpoint and reserve
the final candidate's one embedded source archive for the release producer.

## Independent final-review findings

These are preservation findings against an experimental, fail-closed scaffold;
they are not claims of exploitable production defects because no acquisition
or release workflow was enabled.

- There is no executable socket-acquisition path or final-release workflow.
- Registered loaders check artifact bytes but do not perform full scientific
  reconstruction; one path accepts a caller-supplied raw parent.
- Nested manifest, pass-report, and review records are not yet completely
  validated.
- Exact-schema handling still permits some float32/int32 coercion and SIMBAD
  floating identifiers, and malformed partial-W4 normalization is incomplete.
- Bounded Parquet allocator/page-header enforcement and descriptor-relative,
  durable publication are incomplete.
- Registry ancestry/signature checks do not yet bind the decoded signer key and
  the committed candidate/attestation bytes end to end.
- Transport ordering and retry invariants are incomplete.

Missing verification includes a synthetic 120-page acquisition, durable
restart, final packaging, offline reconstruction, decompression-bomb tests,
signer/ancestry integration, fuzz targets, and a run under the exact registered
CPython 3.14 toolchain.

## Disposition

Preserve the scaffold only as review evidence that can be adapted after v0.1.4
is prospectively frozen. Do not stage data caches, build products, credentials,
local paths, or release artifacts with it. Until the schema is superseded and a
reviewer trust key is prospectively authorized, this branch must not be merged,
tagged, or released.
